# Contractory

Code source et assets du mod **Contractory / SatisfactoryReverse**, version **Alpha 0.8.4** pour Satisfactory.

Ce depot contient uniquement le plugin Contractory. Les fichiers du jeu Satisfactory, du SML et de l'Unreal Engine ne sont pas inclus.

## Installation pour developpement

Placer ce dossier de plugin dans `Mods/SatisfactoryReverse` d'un environnement de developpement Satisfactory Mod Loader compatible. Les dependances SML et Unreal Engine doivent etre installees separement.

## Etat

Version alpha en developpement. Le depot ne contient pas de version compilee prete a installer.
